# Range Coach

A clickable product prototype for a decision-first No-Limit Hold'em coach. It teaches a reusable loop: build the opponent's range, judge how capped it is, choose a coherent response, and explain the evidence.

The current prototype includes three authored scenarios, deterministic feedback and Socratic follow-up prompts. It does not simulate gambling, connect to poker clients or provide real-time assistance.

Product research and requirements are in `docs/`.

## Run locally

```bash
npm install
npm run dev
```
